Sage WASM Search Demo

Loads a FASTA and a set of spectra directly in the browser, builds a local sage-core database in WebAssembly, and runs live matching.

Run search

Live-search pipeline runs one spectrum at a time directly in the browser. The dataset is built from PXD003881 has 100 spectra samples from one mzML file, Each spectrum is searched on demand (real-time search) as you navigate to keep runtime light:

Search options

Adjust every engine option exposed by the WASM binding. These controls are applied lazily — click Apply options to rebuild the search index and re-run the current spectrum. Inputs are represented as sliders, dropdowns, checkboxes, and JSON editors.
